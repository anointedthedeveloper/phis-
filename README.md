# PHIS Receipts

Downloads for **PHIS Receipts**, the receipt app for Peter Harvard International Schools. It runs on Windows and Android and keeps receipts in sync online.

Get the latest version from the **[Releases](../../releases/latest)** page.

## Install

**Windows**
1. Download `PHIS-Receipts-Windows.zip`.
2. Unzip it somewhere you can write to, for example `C:\PHIS` (not Program Files).
3. Open `Phis.App.exe` and sign in.

**Android**
1. Download `PHIS-Receipts-Android.apk` on the phone.
2. Open it and allow "install unknown apps" if asked.
3. Open **PHIS Receipts** and sign in.

## Updates

The app checks this page when it starts and offers new versions automatically. You can also use **Settings, About and updates, Check for updates**.

## Need help?

Contact your school administrator for an account or a password reset.
